# Запуск FitPulse AI: пошагово

Всё ниже делается один раз. Команды вводятся в терминале (на Mac: программа «Терминал», на Windows: PowerShell) внутри папки проекта.

## Что понадобится

- Node.js версии 20 или новее: https://nodejs.org (кнопка LTS)
- Git: https://git-scm.com
- Аккаунт Google (таблица и почта)
- Аккаунт GitHub (код) и Render (хостинг): https://github.com, https://render.com
- Ключ ИИ-модели. Проще всего Gemini: https://aistudio.google.com, кнопка «Get API key». У Google есть бесплатный уровень, лимиты могут меняться.

Папку проекта держите НЕ в iCloud, OneDrive, Dropbox или Google Drive: установщик ai-employees отказывается работать в синхронизируемых папках. Подойдёт, например, `Documents/fitpulse-agency` без синхронизации или `C:\fitpulse-agency`.

## Шаг 1. Нанять команду (это нужно показать в видео)

```bash
npm run hire
```

Скрипт скачает репозиторий ai-employees, наймёт 8 сотрудников официальным установщиком и создаст файлы `.installed.json`. В конце должно быть: `8 employees hired (1 Project Manager + 7 specialists)`.

## Шаг 2. Google-таблица и почта

1. Создайте новую Google-таблицу, назовите её, например, `FitPulse AI Ledger`.
2. Меню «Расширения» → «Apps Script». Удалите всё в редакторе и вставьте содержимое файла `bridges/apps-script/Code.gs`.
3. Вверху в блоке `CONFIG` заполните:
   - `SECRET`: придумайте длинный пароль (он же будет `BRIDGE_SECRET`);
   - `BOSS_EMAIL`: ваша почта для ежедневных писем;
   - `REPORT_HOUR`: час отправки письма (18 = в шесть вечера);
   - `SERVER_URL`: заполните позже, после шага 5.
4. «Начать развертывание» → «Новое развертывание» → тип «Веб-приложение». «Запуск от имени»: я. «У кого есть доступ»: все. Нажмите «Развернуть», разрешите доступ и скопируйте URL веб-приложения.
5. В таблице нажмите «Настройки доступа» → «Все, у кого есть ссылка» → «Читатель». Эту ссылку вы сдадите преподавателю.

## Шаг 3. Проверка на своём компьютере

1. Скопируйте файл `.env.example` и назовите копию `.env`.
2. Заполните в нём: `BOSS_PASSWORD`, `SESSION_SECRET` (любой длинный текст), `GEMINI_API_KEY`, `SHEETS_WEBAPP_URL` (URL из шага 2), `BRIDGE_SECRET` (тот же, что `SECRET` в скрипте), `SHEET_URL` (ссылка на таблицу), `BOSS_EMAIL`, `CLIENT_NAME` (название клуба-клиента).
3. Запустите:

```bash
npm start
```

4. Откройте http://localhost:3000, войдите (логин `boss`, пароль из `.env`), назначьте задачу и убедитесь, что она появилась в таблице на листе `Ledger`.

## Шаг 4. Код на GitHub

Создайте на GitHub новый пустой репозиторий, затем:

```bash
git init
git add .
git commit -m "FitPulse AI agency"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/fitpulse-agency.git
git push -u origin main
```

Файл `.env` с паролями в GitHub не попадёт: он указан в `.gitignore`.

## Шаг 5. Хостинг на Render

1. Render → New → Web Service → подключите репозиторий.
2. Build Command: `echo no build step`. Start Command: `node server/index.mjs`. Тариф Free.
3. В разделе Environment добавьте те же переменные, что в `.env`, и `TIMEZONE=Europe/Kyiv`.
4. После запуска Render покажет адрес вида `https://fitpulse-agency.onrender.com`. Добавьте переменную `PUBLIC_URL` с этим адресом.
5. Вернитесь в Apps Script: впишите этот адрес в `SERVER_URL`, затем «Начать развертывание» → «Управление развертываниями» → карандаш → версия «Новая версия» → «Развернуть».
6. В редакторе Apps Script выберите функцию `setupTriggers` и нажмите «Выполнить». Это включает ежедневное письмо и «будильник» раз в 10 минут, который не даёт бесплатному хостингу уснуть и запускает ежедневные задачи сотрудников.

Проверка письма: в дашборде «Reports» → «Email report now».

## Шаг 6. Что сдавать

| Что | Где взять |
|---|---|
| Одобренная заявка | Документ Agency Proposal |
| План агентства | Отдельный документ на 1–2 страницы (роли есть в `agency/team.json`, схема в README) |
| Ссылка на дашборд и тестовый логин | Адрес Render, логин `boss` и пароль |
| Ссылка на таблицу | Шаг 2, пункт 5 |
| 3 письма за разные дни | Скриншоты из почты: систему нужно запустить минимум за 3 дня до сдачи |
| GitHub | Ссылка на репозиторий |
| Видео 8–15 минут | Запишите: `npm run hire` в терминале, таблицу, письмо, вход в дашборд, задачу для PM и для сотрудника, смену статусов, отчёты, 6 контрольных вопросов в чате |
| Презентация | Отдельно |

## Если что-то не работает

- На карточках «Team» вверху есть цветные метки: зелёная значит подключено, жёлтая значит не настроено.
- Задача в статусе Blocked: откройте её, причина написана внутри. После исправления нажмите «Retry task».
- Таблица не заполняется: проверьте, что `BRIDGE_SECRET` совпадает с `SECRET` в скрипте и что у веб-приложения доступ «все».
- Письмо не приходит: выполните в Apps Script функцию `sendDailyReport` вручную и посмотрите ошибку в журнале.
